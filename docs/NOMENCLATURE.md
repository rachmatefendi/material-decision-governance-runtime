# Nomenclature: EOS → DGR → MDGR

## Current canonical name

**Material Decision Governance Runtime (MDGR)**

## Historical terminology

The research preprint included in this repository is titled:

**Governing Before Reasoning: EOS, a Decision Governance Specification for High-Stakes LLM Systems**

It uses:

- **EOS** — Expert Operating System
- **DGR** — Decision Governance Runtime

## Why this repository uses MDGR

The later architecture work separates the decision-governance function from broader operating-system terminology.

`MDGR` makes the boundary explicit:

- **Material Decision** — the runtime activates for consequential decision paths rather than every AI task;
- **Governance** — the purpose is control, authority, and bounded decision state, not general analysis;
- **Runtime** — the specification describes behavior during decision processing and, at stronger conformance levels, external validation and execution gating.

## Compatibility rule

For MDGR v1.0:

```text
EOS / DGR paper
        ↓
historical research basis
        ↓
MDGR
canonical repository name
```

This naming normalization does **not** by itself prove that every EOS/DGR paper statement has been formally migrated into a frozen standalone MDGR specification.

That migration is a publication-hardening task.


## Public repository treatment

The historical paper remains part of the research lineage, but its PDF is intentionally not distributed in the MDGR v1.0 repository. The repository license therefore does not govern the paper.
